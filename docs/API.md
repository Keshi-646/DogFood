# API Quick Reference

- `POST /api/register` — participant registration
- `POST /api/login` — login
- `POST /api/logout` — logout
- `POST /api/teams` — create team
- `POST /api/submissions` — create submission
- `POST /api/assignments` — organizer/admin assignment
- `GET /api/judge/assignments` — current judge assignments
- `GET /api/judge/scores/<submission_id>` — assignment-scoped scores
- `POST /api/judge/score` — judge score
- `POST /api/normalize` — organizer/admin normalization
- `GET /api/results` — public results
- `GET /api/gallery` — public gallery
- `GET /api/export/submissions.csv` — organizer/admin CSV export
